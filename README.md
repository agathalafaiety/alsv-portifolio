# Agatha Lafaiety | Portfólio

Este repositório reúne o código do meu portfólio profissional, onde compartilho minha trajetória, experiências, artigos e projetos nas áreas de Engenharia de Software e Inteligência Artificial.

🌐 [Acesse o portfólio](https://agathalafaiety.com.br)

## Tecnologias

- React
- TypeScript
- Vinext
- Vite
- Tailwind CSS

## Como executar localmente

```bash
git clone https://github.com/agathalafaiety/alsv-portifolio.git
cd alsv-portifolio/projects/portfolio
npm install
npm run dev -- --port 4317
```

Depois, acesse `http://localhost:4317` no navegador.
